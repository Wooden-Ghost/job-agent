## 0. 一句话结论

**用 `adb` + `uiautomator dump` 读原生控件树**：不装任何客户端库、不做 OCR、不碰网页反爬。
招聘 App 是原生安卓，界面文字本来就是明文，np 识别这一步根本不需要存在。

## 3. 采集流水线（当前设计）

```
[1] 选 tab（Python / 爬虫 / 数据采集）        ← 零输入
[2] harvest.py 抓列表（多屏滑动，去重）
[3] 逐条 tap 卡片标题坐标 → 详情页
[4] 详情页 dump → JD 全文 + 公司四要素
[5] 返回列表（BACK）→ 校验回到原滚动位置
[6] 交 pipeline.py：去重闸 → L1 打分 → 阈值门 → L2 背调（走公司库缓存）
```

卡片字段（`harvest.py` 已解析）：`title / salary / company / companySize / companyStage / tags / hr / activity / area / tap`。

## 5. 踩过的坑与对策（全部已修）

| # | 坑 | 表现 | 对策 |
|---|---|---|---|
| 1 | `exec-out uiautomator dump /dev/tty` 不稳 | 只回一句 `UI hierchary dumped to: /dev/tty`，零节点 | **落盘 `/sdcard/ui_dump.xml` 再 `exec-out cat`** |
| 2 | 滑完解析出 0 张卡就判定「到底」 | 3 屏只抓到 5 条 | 0 条时 **等 3 秒重读一次**；只有「读到卡片但全是旧的」才算到底 |
| 3 | 冷启动品牌闪屏 8–10 秒 | `ERROR: null root node returned by UiTestAutomationBridge.` | `dump_xml(attempts=3)` + `sleep 1.5` 重试 |
| 4 | 屏幕转屏 | `rotation="3"`，`bounds` 漂移 | 锁竖屏 |
| 5 | 中文打不进搜索框 | `adb shell input text` 注入的是 ASCII，绕过 IME | **不用输入法**：走 tab / 筛选面板 / 求职期望 |
| 6 | 目测坐标 | 点「成都」点到「西安」 | 一律取 `dump_ui.py` 的 `center` |
| 7 | 误触「附近」+ POI 选择器 | 地点变成「成都联合产权交易所」 | 只用 `切换城市` 的省级入口，永不碰「附近」 |
| 8 | PowerShell `>` 重定向截图 | 543,970 字节但 `read_image` 报 malformed | **`cmd /c "adb exec-out screencap -p > x.png"`**，正确产物约 285KB |
| 9 | 求职期望上限 | —— | **最多 3 个**，超过要删 |
